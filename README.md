# Stellar Burgers

Учебный проект на React и TypeScript: главная страница бургерной с каталогом ингредиентов, конструктором заказа и модальными окнами.

## Возможности

- загрузка ингредиентов из API;
- отображение ингредиентов по категориям;
- конструктор бургера с подсчётом стоимости;
- перетаскивание ингредиентов внутри конструктора;
- модальные окна с деталями ингредиента и информацией о заказе.

## Технологии

- React;
- TypeScript;
- Vite;
- CSS Modules;
- React DnD;
- UI-компоненты Stellar Burgers.

## Sprint 4

Проект изначально реализован на React + TypeScript. В рамках четвертого спринта выполнена сверка типизации компонентов, утилит, API-слоя и Redux-хранилища с чек-листом проектной работы.
